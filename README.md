# Tushar React Portfolio

This is a React + Vite + Tailwind CSS portfolio for **Tushar Zade**.

## How to run

1. Make sure you have **Node.js** installed.
2. Extract this zip file.
3. Open a terminal inside the project folder.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the dev server:

   ```bash
   npm run dev
   ```

6. Open the URL shown in the terminal in your browser.

You can replace `public/profile.svg` with your own image (e.g. `profile.jpg`) and update links/content in `src/App.jsx`.
